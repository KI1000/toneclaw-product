# ToneClaw 外部接入与扩展地图

> 记录时间：2026-10-03 21:04:07 CST
> 状态：接入与扩展规划 SSOT
> 目标：明确第一版做什么、预留什么、延后什么，避免后续业务架构被外部系统反向绑定。

## 1. 总原则

ToneClaw 核心模型保持平台无关；外部系统通过 Adapter、DataSource、Connector、Job 和 Mapping 接入。

```text
ToneClaw Core
→ Adapter / Connector
→ External System
```

不允许外部系统的私有字段、私有状态和错误码直接污染核心业务模型。

## 2. 销售平台接入

| 平台 / 渠道 | 当前阶段 | 说明 |
| --- | --- | --- |
| Temu | P0 | 第一个 Marketplace；验证店铺、选品、商品图、Listing、上架、订单和履约闭环 |
| TikTok Shop | Phase 4B / 后续 | 复用 PlatformFitAssessment、ListingDraft、PublishJob、Order 模型 |
| Amazon | Phase 4B / 后续 | 需要更强类目、属性、合规、库存和广告数据模型 |
| Shopee | 后续 | 东南亚市场候选平台 |
| AliExpress | 后续 | 跨境市场候选平台 |
| 独立站 / Shopify | 后续 | 属于独立站渠道，不进入 P0 |

P0 只接入 Temu 店铺，但核心对象不能被 Temu 绑定。

## 3. 货盘与供应商数据源

| 数据源 | 当前阶段 | 说明 |
| --- | --- | --- |
| 手工录入 | P0 | 基础能力，用于补充和修正货盘数据 |
| Excel / CSV / JSON 导入 | P0 | 第一版主要货盘来源 |
| 1688 | Phase 2+ / 后续 | 通过官方开放能力接入，不做爬虫或逆向 |
| CJ Dropshipping | 后续 | 可作为供应商生态候选 |
| Doba | 后续 | 可作为供应商生态候选 |
| 本土货盘 / 精选货盘 | 后续 | 可作为精选货源或运营推荐来源 |
| 自建供应商池 | 后续 | 面向长期供应商关系、资质和履约能力 |

架构关系固定为：

```text
External Goods Source
→ DataSource Adapter
→ Standardized SourcingItem
→ SelectionDecision
→ Product
→ Platform Listing
```

1688 不是货盘本身，而是货盘数据源之一。

## 4. AI 与模型能力

| 能力 | 当前阶段 | 说明 |
| --- | --- | --- |
| DSH Agent / Session | P0 | 内嵌引擎，不作为用户可见产品 |
| 文本生成 | P0 | 用于标题、卖点、描述、关键词、经营摘要 |
| 商品图生成 | P0 | 用于主图、细节图、场景图和图片变体 |
| 图片处理 | P0 | 裁剪、压缩、尺寸适配、白底图辅助 |
| 翻译 | P0 / 后续 | 按目标平台和站点生成多语言内容 |
| OCR / 图片理解 | 后续 | 可用于供应商图片信息提取和合规预检 |
| 视频生成 | 后续 | 不进入 P0 |
| 广告素材生成 | 后续 | 不进入 P0 |
| 客服 Agent | 后续 | 不进入 P0 |
| 自动采购 Agent | 后续 | 高风险，不进入 P0 |

所有 AI 动作必须生成 `UsageRecord`，包括模型、场景、输入输出 Token、成本估算和审计信息。
